# 协同｜同频会议与协作系统

项目团队会议与协作管理平台。主任务独立于会议，由组长分配并验收；负责人可创建私有个人子任务、发布关联工作日志和提交成果。本地运行后，支持成员在同一项目中安排会议、记录分工和日志、查看团队动态，并管理会议录音与资料分析。

## 已实现功能

- 账号注册、登录、个人资料、创建/切换项目、邀请码加入、成员管理和项目归档。
- 会议安排、状态流转、应参会名单、签到/补签、资料、纪要和操作记录。
- 历史会议工作分配追溯、主任务负责人变更历史、本人工作日志，以及项目蛇形时间线和个人时间线回顾。
- 会议麦克风录音或录音上传；转写稿可校订、保留版本，并在确认后用于纪要。
- 录音上传前记录授权确认人和时间；服务器通过 FFprobe 核验真实时长，执行转写前会检查文件格式、大小、会议状态与单场数量。
- 会议资料与转写稿可选择后生成分析草稿；草稿需人工核对，不会自动覆盖纪要。
- 项目附件下载、文字文档与便携文档导出、项目备份与恢复、个人待办和站内通知。

## 项目角色、主任务与工作日志

每个项目只有一名组长，其余成员为组员；创建项目的人默认是组长。同一账号在不同项目中的角色独立判断，不设置“项目经理”角色。权限由服务端按当前项目成员身份再次校验，界面隐藏操作入口只用于避免误操作。

| 操作 | 组长 | 组员 |
| --- | --- | --- |
| 查看项目资料、成员、共享会议与日志 | 允许 | 允许 |
| 修改项目资料、邀请/移除成员、转让组长、归档 | 允许 | 不允许 |
| 创建主任务、修改要求、改派、取消/恢复/重新打开、验收/退回 | 允许 | 不允许 |
| 开始、提交本人负责的主任务 | 仅本人负责的任务 | 仅本人负责的任务 |
| 创建和维护个人子任务 | 仅本人创建的内容 | 仅本人创建的内容 |
| 管理本人工作日志 | 允许 | 允许 |
| 修改他人已发布日志 | 不允许 | 不允许 |

主任务独立于会议。组长创建任务时填写标题、工作说明、负责人、优先级、截止时间和验收标准；可选上传参考附件。任务保存后为“待处理”，负责人可以立即查看。主流程为：待处理 → 进行中 → 待验收 → 已完成；验收退回后回到进行中。首次创建不能直接完成，所有取消、恢复、重开、改派、提交和验收都会保留操作人及历史记录。

任务负责人可以选择创建个人子任务，也可以不拆分。子任务只向创建者本人显示，不进入团队时间线、共享报表、项目备份或验收材料；改派不转交个人拆分。子任务状态与主任务及今日待办相互独立，不阻止主任务提交或验收。

任务日志必须关联至少一项同项目内本人当前负责的主任务；通过复选框可以逐项勾选或取消关联。项目日常日志的任务关联可选。未发布的新日志自动保存到本人草稿区，草稿仅本人可见并支持继续编辑、删除和发布；撤回的未引用日志也可重新发布。提交验收要求提交说明、已发布且关联该任务的日志，以及成果链接或附件。每次提交保存当时引用的日志版本。已发布日志由作者维护并保留版本；作者可导出 DOCX。

日志作者可按本人负责的主任务建立个人分类，并将自己的已发布日志加入分类。分类及分类关系仅作者本人可见，删除分类不会删除日志；选择分类是可选操作，不影响任务日志发布。

## 验收与测试

```powershell
npm test
npm run test:e2e
```

`npm test` 在临时数据目录运行真实本地 HTTP 服务的模块和 API 集成测试。`npm run test:e2e` 使用已安装的 Chrome headless，通过 CDP 鼠标点击和表单输入验收真实浏览器界面，并使用隔离 fixture；测试不会写入项目的 `data/store.json`、`data/uploads/` 或 `.env`。浏览器脚本默认查找 `C:\Program Files\Google\Chrome\Application\chrome.exe`，也可用 `CHROME_BIN` 指定 Chrome 路径。AC-01～AC-30 的执行证据和未覆盖边界见 [docs/验收执行记录.md](docs/验收执行记录.md)。

## 模型与服务对应

| 功能 | 服务/模型 | 需要配置 |
| --- | --- | --- |
| 录音转文字 | 阿里云百炼 Paraformer `paraformer-v2` | 百炼接口密钥、私有 OSS 桶及访问密钥 |
| 转写稿、纯文本资料分析 | 阿里云百炼 DeepSeek `deepseek-v4.1-flash-1017`；备用 `deepseek-v4.1-flash` | 百炼接口密钥 |
| PDF、文字文档、表格、演示文稿、图片分析 | 文件先转为 PDF，再用阿里云百炼 Qwen `qwen3.8-flash`；备用 `qwen3.8-max-0902` | 百炼接口密钥、私有 OSS；文字文档/表格/演示文稿/图片还需要九云图应用码（AppCode） |
| 办公文档和图片转 PDF | 华为云市场九云图文档格式转换服务 | `YUNTU_APIG_APPCODE`（九云图应用码） |

同一份百炼接口密钥用于 Paraformer、DeepSeek 和 Qwen。使用录音转写、PDF 分析或格式转换时，OSS 桶须设为私有；OSS 密钥建议使用权限受限的 RAM 子用户。云端免费额度、模型开通状态和服务价格以各自控制台为准。系统会在执行第三方处理前提示并要求确认。

## 本机启动

需要 Node.js 18 或更新版本。文档导出和项目备份功能还需要 Python 3、`python-docx` 与 `PyMuPDF`。

```powershell
cd F:\huiyi\projects\meeting-collab-platform
npm start
```

打开 <http://localhost:5183>。演示账号密码均为 `demo1234`：`lin`（组长）、`zhou`、`chen`、`xu`（组员）。数据保存在 `data/store.json`，附件保存在 `data/uploads/`。

## 配置云端服务

`.env.example` 只包含变量名和空白密钥，不含真实服务密钥，可以提交到 GitHub。每位需要测试云端功能的开发者在项目根目录单独创建本机 `.env`：

```powershell
Copy-Item .env.example .env
notepad .env
```

在 `.env` 中填写自己的百炼接口密钥、OSS 桶/地域/访问密钥；测试文字文档、表格、演示文稿或图片转 PDF 时，再填写九云图应用码（AppCode）。保存后重启 `npm start`。只改代码、不测试云服务的队友可以保留密钥为空。**不要把 `.env`、任何服务密钥或九云图应用码提交到 GitHub、发在群聊或写进前端代码。**`.env` 已由 `.gitignore` 排除。

测试路径：登录演示账号并打开会议；上传录音后发起转写可验证 Paraformer；选择纯文本资料或已完成的转写稿进行分析可验证 DeepSeek；选择 PDF 验证 Qwen；选择文字文档、表格、演示文稿或图片还会验证九云图转换。转写、分析及转换服务必须先完成对应凭证配置。

录音样例记录：演示数据中有一次 `OSR_cn_000_0072_8k.wav` 的真实 `paraformer-v2` 识别结果，服务状态为完成，约 20 秒音频返回 75 字和 2 段识别结果，服务往返约 6 秒。文本整体连贯；该样例没有随项目保存权威逐字稿，因此不报告字错率，正式会议内容仍需人工校对。

## FFmpeg / FFprobe

录音上传需要 FFprobe 在服务端核验真实时长；使用 `paraformer-8k-v2` 或处理浏览器 WebM 录音还会用到 FFmpeg。Windows 可用 `winget install --id Gyan.FFmpeg -e` 安装，重开终端后运行 `ffprobe -version` 和 `ffmpeg -version` 验证。若命令无法识别，在本机 `.env` 设置 `FFPROBE_PATH`、`FFMPEG_PATH` 为对应可执行文件的完整路径，然后重启服务。FFmpeg 不随仓库提交，队友需要在自己的电脑单独安装。

## GitHub 协作与部署说明

仓库提交 `.env.example`，不要提交 `.env`。队友拉取代码后按上节复制模板并填写**自己的**凭证；如果使用同一个运行环境，可由环境负责人在该环境的密钥配置中设置一次，其他协作者不需要改 API 代码。

当前项目使用 JSON 文件保存数据和本地目录保存附件，适合本地演示和小规模协作验证。Render 等云平台上的本地磁盘可能随重启或重新部署而重置；多人长期使用前应配置持久磁盘，并将数据和附件迁移到数据库与对象存储。部署平台的 服务密钥应填写在服务的环境变量/密钥设置中，不能放入仓库。FFmpeg 若用于云端转码，也必须在服务环境安装并设置可执行路径。

## 当前限制

这是本地原型，上传数量的并发预留和转写去重只在单个服务进程内生效，不具备数据库事务和多进程并发控制。第三方转写、转换、分析是否可用取决于账号权限、地域、额度和网络；演示数据不是线上业务数据。智能分析结果为草稿，必须由成员核对。
