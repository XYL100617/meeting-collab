# 协同｜同频会议与协作系统

项目团队会议与协作管理平台。本地运行后，支持成员在同一项目中安排会议、记录分工和日志、查看团队动态，并管理会议录音与资料分析。

## 已实现功能

- 账号注册、登录、个人资料、创建/切换项目、邀请码加入、成员管理和项目归档。
- 会议安排、状态流转、应参会名单、签到/补签、资料、纪要和操作记录。
- 工作分配、负责人变更历史、本人工作日志，以及项目和个人时间线。
- 会议麦克风录音或录音上传；转写稿可校订、保留版本，并在确认后用于纪要。
- 会议资料与转写稿可选择后生成分析草稿；草稿需人工核对，不会自动覆盖纪要。
- 项目附件下载、文字文档与便携文档导出、项目备份与恢复、个人待办和站内通知。

## 模型与服务对应

| 功能 | 服务/模型 | 需要配置 |
| --- | --- | --- |
| 录音转文字 | 阿里云百炼 Paraformer `paraformer-v2` | 百炼接口密钥、私有 OSS 桶及访问密钥 |
| 转写稿、纯文本资料分析 | 阿里云百炼 DeepSeek `deepseek-v4.1-flash-1017`；备用 `deepseek-v4.1-flash` | 百炼接口密钥 |
| PDF、文字文档、表格、演示文稿、图片分析 | 文件先转为 PDF，再用阿里云百炼 Qwen `qwen3.8-flash`；备用 `qwen3.8-max-0902` | 百炼接口密钥、私有 OSS；文字文档/表格/演示文稿/图片还需要九云图应用码（AppCode） |
| 办公文档和图片转 PDF | 华为云市场九云图文档格式转换服务 | `YUNTU_APIG_APPCODE`（九云图应用码） |

同一份百炼接口密钥用于 Paraformer、DeepSeek 和 Qwen。使用录音转写、PDF 分析或格式转换时，OSS 桶须设为私有；OSS 密钥建议使用权限受限的 RAM 子用户。云端免费额度、模型开通状态和服务价格以各自控制台为准。系统会在执行第三方处理前提示并要求确认。

## 本机启动

需要 Node.js 18 或更新版本。文档导出和项目备份功能还需要 Python 3、`python-docx` 与 `PyMuPDF`。

## 配置云端服务

`.env.example` 只包含变量名和空白密钥，不含真实服务密钥，可以提交到 GitHub。每位需要测试云端功能的开发者在项目根目录单独创建本机 `.env`：

```powershell
Copy-Item .env.example .env
notepad .env
```

在 `.env` 中填写自己的百炼接口密钥、OSS 桶/地域/访问密钥；测试文字文档、表格、演示文稿或图片转 PDF 时，再填写九云图应用码（AppCode）。保存后重启 `npm start`。只改代码、不测试云服务的队友可以保留密钥为空。**不要把 `.env`、任何服务密钥或九云图应用码提交到 GitHub、发在群聊或写进前端代码。**`.env` 已由 `.gitignore` 排除。

测试路径：登录演示账号并打开会议；上传录音后发起转写可验证 Paraformer；选择纯文本资料或已完成的转写稿进行分析可验证 DeepSeek；选择 PDF 验证 Qwen；选择文字文档、表格、演示文稿或图片还会验证九云图转换。转写、分析及转换服务必须先完成对应凭证配置。

## FFmpeg（可选）

默认 `paraformer-v2` 不需要 FFmpeg。只有使用 `paraformer-8k-v2` 备用模型（音频重采样）或腾讯云转写并处理浏览器 WebM 录音时才需要。Windows 可用 `winget install --id Gyan.FFmpeg -e` 安装；安装后重新打开终端并运行 `ffmpeg -version` 验证。若命令仍无法识别，可在本机 `.env` 设置 `FFMPEG_PATH` 为 `ffmpeg.exe` 的完整路径，之后重启服务。FFmpeg 不随仓库提交，队友需要在自己的电脑单独安装。

## GitHub 协作与部署说明

仓库提交 `.env.example`，不要提交 `.env`。队友拉取代码后按上节复制模板并填写**自己的**凭证；如果使用同一个运行环境，可由环境负责人在该环境的密钥配置中设置一次，其他协作者不需要改 API 代码。

当前项目使用 JSON 文件保存数据和本地目录保存附件，适合本地演示和小规模协作验证。Render 等云平台上的本地磁盘可能随重启或重新部署而重置；多人长期使用前应配置持久磁盘，并将数据和附件迁移到数据库与对象存储。部署平台的 服务密钥应填写在服务的环境变量/密钥设置中，不能放入仓库。FFmpeg 若用于云端转码，也必须在服务环境安装并设置可执行路径。

## 当前限制

这是本地原型，不具备数据库事务和多进程并发控制。第三方转写、转换、分析是否可用取决于账号权限、地域、额度和网络；演示数据不是线上业务数据。智能分析结果为草稿，必须由成员核对。
