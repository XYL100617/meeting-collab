# 协同｜同频会议与协作系统

面向项目团队的本地协作平台。围绕项目、会议、责任分工和工作日志记录协作过程，并按项目成员身份隔离数据与权限。

## 已完成模块

- **账户与个人资料**：左下角当前用户区域和右上角头像菜单均可进入个人账户；支持注册、登录、退出、默认头像、头像上传、显示名称和登录账号修改、密码修改。
- **项目空间**：创建和切换项目、项目邀请、成员管理、项目设置、归档及归档查询。
- **会议管理**：创建和调整会议、状态流转、取消原因、参会名单、本人签到、组长补签、会议资料与纪要。
- **工作分配**：新增和调整责任人、计划日期、变更历史，以及“分配给我”和按成员查看。
- **工作日志**：发布和修改本人日志，关联会议或分工，上传附件并导出 Word/PDF。
- **时间线**：查看项目动态、个人记录和成员时间线，支持类型、成员、日期筛选及记录跳转。
- **内容与数据管理**：纪要和日志支持常用富文本、表格和图片；支持项目 ZIP 备份与恢复。
- **界面**：概览、会议、分工、日志和时间线等列表支持滚动；提供桌面及窄屏布局。

## 启动

需要 Node.js 18 或更新版本。Word/PDF 导出和 ZIP 备份恢复需要 Python 3；Word/PDF 还需 `python-docx` 与 `PyMuPDF`。

```powershell
cd F:\huiyi\projects\meeting-collab-platform
npm start
```

访问 `http://localhost:5183`。端口固定为 5183；若提示端口占用，请先停止旧的项目服务。

## 交付说明

当前版本适用于本地演示和功能展示，数据保存在 `data/store.json`，附件保存在 `data/uploads/`。项目数据和文件操作有服务端身份及权限校验。

当前原型使用单进程 JSON 文件存储，没有数据库事务或跨进程并发控制，不适合生产环境多人部署。附件未做恶意文件扫描；复杂 Word/PDF 排版及完整浏览器端到端验收仍需进一步验证。系统不包含任务审批/验收、贡献排名、AI 总结或音视频会议。
